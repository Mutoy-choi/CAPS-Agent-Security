접근성

CAPS 문서는 키보드와 보조기술을 포함해 가능한 많은 사용자가 설치·검색·검증 절차에 접근할 수 있도록 설계합니다.

지원 목표

  • 논리적인 heading과 landmark 구조
  • 본문 바로가기 링크와 visible keyboard focus
  • 고대비 텍스트와 forced-colors 지원
  • 200% 확대와 좁은 화면에서 가로 손실 없는 레이아웃
  • prefers-reduced-motion 존중
  • 명령어를 텍스트로 제공해 복사·확대·스크린리더 사용 가능
  • 한국어 본문과 영어 기술 키워드 병기

문제 제보

접근성 장벽을 발견하면 GitHub Issue에 사용 환경, 페이지, 기대 동작을 남겨주십시오. 보안 취약점은 공개 Issue 대신 비공개 Security Advisory를 사용하십시오.
