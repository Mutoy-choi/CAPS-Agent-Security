CAPS Marketplace는 GitHub 저장소와 Pages의 marketplace.json 두 경로를 제공합니다. Agent Skills 레지스트리와 원본 SKILL.md도 정적 URL로 공개되도록 구성되어 있어 웹 검색, AI 검색, 문서 검색과 자동 설치 도구가 같은 canonical 정보를 사용할 수 있습니다.

공개 조건: 현재 private 저장소는 일반 웹 검색에 노출되지 않습니다. 외부 공개 전에 저장소 또는 전용 배포 저장소를 public으로 전환하고 GitHub Pages를 활성화해야 합니다.
