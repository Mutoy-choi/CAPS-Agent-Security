Native Plugin & Extension packages

같은 two-Skill core를 각 제품의 native package 형식으로 배포합니다.

ChatGPT / Codex

.codex-plugin/plugin.json과 skills/가 저장소 루트 및 plugins/caps-unlock/에 있습니다. 로컬 사용은 ./install.sh codex로 시작할 수 있으며, public universal directory listing은 별도 제출 이후 제공됩니다.

Claude Code

claude plugin marketplace add Mutoy-choi/CAPS-Agent-Security
claude plugin install caps-unlock@caps-labs --scope user

Gemini CLI

gemini extensions install https://github.com/Mutoy-choi/CAPS-Agent-Security --auto-update

Gemini package에는 GEMINI.md, custom commands와 Agent Skills가 포함됩니다.

Plugin/extension 설치만으로 Runtime, MCP, telemetry 또는 active probe가 시작되지 않습니다.
